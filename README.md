# 📱 Flutter Concepts Demo

A beginner-friendly Flutter application developed as **Assignment 4 — Concepts Demo App**.
The project demonstrates three important Flutter concepts in a single application:

* 📝 Form handling and validation
* 🖼️ Local images, assets, and custom fonts
* ✨ Interactive animations using `AnimatedContainer`

The application also demonstrates **screen navigation using named routes**.

---

## 🎯 Assignment Objective

The objective of this project is to develop a Flutter application that demonstrates:

1. Accepting and validating user information using Flutter Forms.
2. Displaying local images using `Image.asset()`.
3. Using a custom font with `ThemeData`.
4. Creating a responsive image grid using `GridView`.
5. Creating interactive animations using `AnimatedContainer`.
6. Navigating between multiple screens using `Navigator.pushNamed()`.

---
